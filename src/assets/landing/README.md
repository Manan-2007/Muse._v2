# Landing page artwork

Drop a screenshot in here and it appears on the landing page. Globbed at build
time — nothing to import, nothing to register.

| File | Where it lands |
| --- | --- |
| `listen.png` | The **Listen** section, replacing the built-in queue mock-up |

`.png`, `.jpg`, `.jpeg`, `.webp` and `.avif` all work. Prefer `.webp` or
`.avif` — these are full-width on desktop, and a 2 MB PNG is the largest thing
on an otherwise light page.

Shoot it at the real aspect ratio you want shown; the image is displayed at its
natural proportions inside a rounded glass frame, so there is no cropping to
fight with.
